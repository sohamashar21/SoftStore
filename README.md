# SoftStore

SoftStore is a modern e-commerce web application built using React.js and Tailwind CSS.

## Features

* Product listing
* Add to cart functionality
* Responsive design
* Modern UI components
* Clean and minimal interface

## Technologies Used

* React.js
* JavaScript
* Tailwind CSS
* CSS
* Bootstrap

## Installation

Clone the repository:

```bash id="owzwy5"
git clone https://github.com/sohamashar21/SoftStore.git
```

Go to project folder:

```bash id="2q3vgo"
cd SoftStore
```

Install dependencies:

```bash id="6vjlwm"
npm install
```

Start development server:

```bash id="b3vvdj"
npm start
```
